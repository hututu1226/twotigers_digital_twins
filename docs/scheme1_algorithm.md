# 方案一算法说明：BS-Gated MoE + 角度-时延自编码器

## 1. 设计目标

方案一用于学习如下映射：

```text
H = f(M, x)
```

其中 `M` 是 PLY 场景地图，`x` 是用户三维坐标，`H` 是形状为 `256 x 4 x 192` 的复数 MIMO-OFDM 信道。

该方案遵守以下边界：

- 不进行传统射线追踪；
- 不搜索训练样本邻居，不做距离加权插值；
- 不使用提交后的人工幅度校准；
- 地图只被转换成可学习的神经网络输入；
- 信道功率、基站归属和 outage 全部由监督学习模块预测。

## 2. 数据分析结论

真实数据检查得到：

- 训练样本 4000 条，测试样本 500 条；
- 两组用户各 2000/250 条，空间上有清晰间隔；
- 按欧氏距离选择最近基站会在训练集错分 396 条，因此不能把最近基站当服务小区标签；
- 训练集中 262 条信道严格全零，两个小区分别为 130 和 132 条；
- 非零样本功率跨度超过 120 dB；
- 90% 时延能量通常集中在极少数时延单元；
- 联合角度-时延域比原始天线-频率域显著稀疏；
- 测试位置以若干紧凑空间区域出现，随机验证划分会造成空间泄漏。

因此模型被拆成五个学习任务：

1. 服务基站门控；
2. outage 分类；
3. 对数功率预测；
4. 归一化信道形状预测；
5. 地图与位置联合编码。

## 3. 基站伪标签生成

原始文件没有单独提供基站标签。预处理程序不使用最近基站规则，而采用空间连通性推断：

1. 分别对坐标轴 0 和坐标轴 1 排序；
2. 在保证分割后两侧均至少含 20% 样本的条件下寻找最大归一化间隔；
3. 用最大间隔中点分成两个空间区域；
4. 计算两个区域的质心；
5. 比较两种质心到基站坐标的全局匹配代价，为区域编号赋予 `BS0/BS1`。

本数据自动选择坐标轴 1，得到两个各 2000 条样本的区域。该标签只用于训练门控网络；测试时由网络自行输出基站概率。

## 4. 地图表示

### 4.1 多高度 BEV

PLY 包含 19378 个顶点和建筑高度信息。预处理将顶点栅格化为多通道鸟瞰图：

```text
channel 0: log(1 + 顶点密度)
channel 1: 栅格最大高度
channel 2: z < 3 m 占用
channel 3: 3 m <= z < 10 m 占用
channel 4: 10 m <= z < 25 m 占用
channel 5: z >= 25 m 占用
```

默认分辨率为 4 m。栅格化只保存地图几何上下文，不计算传播路径、反射点、材质系数或射线权重。

### 4.2 链路上下文 Token

对每个候选基站分别生成固定长度地图 Token：

- 在基站和用户之间均匀采样 16 个上下文位置；
- 在用户周围 `3 x 3` 网格采样局部环境；
- 每个位置双线性读取 6 个 BEV 通道；
- 附加归一化绝对坐标、相对用户坐标、链路进度和 Token 类型。

每个用户、每个候选基站得到 `25 x 12` 的 Token 序列。神经网络通过注意力学习哪些 Token 有用。这里没有手工判定 LOS/NLOS，也没有沿线累积障碍损耗。

## 5. 角度-时延信道表示

原始信道：

```text
H in C^[B, M, N, S]
M = Mp * Mv * Mh = 2 * 8 * 16
N = 4
S = 192
```

代码采用阵列展平顺序：

```text
M -> [Mp, Mv, Mh]
```

然后执行：

```text
G = IFFT_S(FFT_Mv,Mh(H))
```

`FFT_Mv,Mh` 将基站阵列转换到角度/波束域，`IFFT_S` 将子载波转换到时延域。所有变换均使用正交归一化 `norm="ortho"`，因此能量守恒。

复数 `G` 的实部与虚部被堆叠为实数通道：

```text
G_real shape = [B, 2 * Mp * N, Mv, Mh, S]
             = [B, 16, 8, 16, 192]
```

逆变换严格执行相反的排列、FFT 和 IFFT。单元测试会检查随机复信道往返误差。

## 6. 功率与形状分解

直接回归原始信道会受到 120 dB 动态范围影响。因此对非零信道定义：

```text
p = log10(mean(|H|^2))
H_shape = H / sqrt(10^p)
```

网络分别预测：

- 标准化对数功率 `p_z`；
- 单位复功率角度-时延形状 `G_shape`。

推理时：

```text
G_pred = G_shape_pred * 10^(p_pred / 2)
H_pred = inverse_angle_delay(G_pred)
```

这不是后处理校准。`p_pred` 是模型输出，直接参与训练损失和反向传播。每个基站使用自己的训练集均值与标准差进行标准化，统计量保存在 `metadata.npz` 中并随模型配置复现。

## 7. 模型结构

### 7.1 LinkContextEncoder

输入包含：

- 用户归一化绝对坐标；
- 用户相对两个基站的坐标；
- 多频 Fourier 坐标编码；
- 两个候选基站各自的地图 Token。

坐标被 MLP 编码成查询向量，地图 Token 被另一个 MLP 编码。通过点积注意力池化得到：

```text
context shape = [B, 2, hidden_dim]
```

### 7.2 基站门控

两个候选基站 context 拼接后输入二分类头：

```text
gate_logits shape = [B, 2]
```

训练使用空间伪标签交叉熵。推理使用 `argmax` 硬路由。不能将两个基站输出的复信道按概率软混合，因为不同基站相位参考不一致，复数相加可能抵消。

### 7.3 Outage 头

每个候选基站 context 输出一个 outage logit。训练时只取真实服务基站对应值计算 BCE。推理时取预测服务基站对应概率：

```text
P_outage >= threshold -> 输出严格全零信道
```

默认阈值 0.5，正式训练后应在空间验证集调节。

### 7.4 功率头

每个候选基站 context 输出标准化对数功率 `p_z`。通过相应基站统计量还原 `log10 power`。

### 7.5 双专家潜变量预测

两个独立 MLP 专家分别学习：

```text
z_bs0 = Expert0(context_bs0)
z_bs1 = Expert1(context_bs1)
```

训练根据真实基站选择一个潜变量，推理根据门控选择。两个专家分离基站相关的相位场和空间传播规律；地图编码器和信道自编码器共享，以避免只有 2000 样本时参数翻倍。

### 7.6 角度-时延自编码器

编码器包含三层 stride-2 3D 卷积：

```text
[16, 8,16,192]
 -> [C, 4, 8, 96]
 -> [2C,2, 4, 48]
 -> [4C,1, 2, 24]
 -> latent
```

解码器使用三层转置卷积恢复原尺寸。GroupNorm 替代 BatchNorm，使小 batch 训练稳定。解码结果再次归一化到单位复功率，防止形状与功率两个分支相互争抢尺度。

4070 配置使用：

```text
base_channels = 16
latent_dim = 256
hidden_dim = 128
```

CPU 冒烟配置刻意缩小到 `base_channels=4, latent_dim=16`。

## 8. 损失函数

### 8.1 门控和 outage

```text
L_bs = CrossEntropy(gate_logits, bs_label)
L_outage = BCE(outage_logit_selected, outage_label)
```

### 8.2 功率

```text
L_power = SmoothL1(p_z_pred, p_z_true)
```

只对非零信道计算功率损失。

### 8.3 潜变量与角度-时延形状

```text
L_latent = MSE(z_pred, stop_gradient(z_encoder))
L_ad = MSE(G_shape_pred, G_shape_true)
```

### 8.4 官方指标对齐损失

从预测信道计算：

```text
L_pas = 1 - cosine(PAS_pred, PAS_true)
L_pdp = 1 - cosine(PDP_pred, PDP_true)
NMSE = ||H_pred - H_true||^2 / ||H_true||^2
L_nmse = log(1 + NMSE)
```

验证和最终报告仍使用官方原始 NMSE。训练使用单调的 `log(1+NMSE)`，防止某个只含极弱信道的小 batch 产生数千倍梯度。默认总损失近似按官方权重设置：

```text
L = 0.4 L_pas + 0.4 L_pdp + 0.2 L_nmse
  + 0.2 L_ad + 0.5 L_latent
  + 0.1 L_power + 0.1 L_bs + 0.2 L_outage
```

联合微调还加入自编码重构辅助损失。严格全零样本不参与 PAS、PDP、功率、潜变量和形状损失，只参与门控与 outage 损失，避免零向量余弦除零。

## 9. 三阶段训练

### 阶段 A：autoencoder

- 只训练信道自编码器；
- 使用真实功率恢复信道；
- 优化角度-时延重构和 PAS/PDP/NMSE；
- 目标是先确定压缩表示的重构上限。

如果这个阶段在验证集上重构分数低，后续坐标网络不可能弥补，应先提高 latent 或卷积容量。

### 阶段 B：predictor

- 冻结自编码器；
- 训练地图/坐标编码器、双专家、门控、outage 和功率头；
- 潜变量目标来自冻结编码器；
- 防止端到端从随机初始化同时学习表示和空间映射。

### 阶段 C：joint

- 解冻全部模块；
- 使用较小学习率联合微调；
- 继续保留潜变量和自编码重构约束；
- 最终 checkpoint 从该阶段的空间验证分数选择。

## 10. 空间块验证

预处理不是随机抽样验证点，而是：

1. 每个基站区域分别进行位置 K-means 分块；
2. 随机选择完整空间块进入验证集；
3. 保证训练和验证在地理上形成空洞；
4. 当前预处理得到 3369 条训练和 631 条验证样本。

该方式更接近测试点的空间留空分布。模型选择应依据空间验证分数，不能只看训练损失。

## 11. 推理流程

对每个测试位置：

1. 读取预计算地图 Token；
2. 编码两个候选链路 context；
3. 门控选择 BS0 或 BS1；
4. 对应 outage 头判断是否输出零信道；
5. 对应专家预测 latent；
6. 共享解码器生成单位功率角度-时延形状；
7. 功率头恢复尺度；
8. 逆变换为 `H[256,4,192]`；
9. 分块写入 `complex64` NPY，避免一次性占用大内存。

## 12. 风险与建议消融

正式调参应至少记录以下消融：

- 无地图 Token，仅坐标；
- 单共享专家与双专家；
- `latent_dim` 为 128/256/512；
- 不同 outage 阈值；
- `Mp,Mv,Mh` 展平顺序；
- 仅 AD-MSE 与加入 PAS/PDP/NMSE；
- 不同空间验证块种子。

主要风险：

- 阵列展平顺序如果与组委会内部定义不同，会降低 PAS；
- 对数功率回归可能被极弱非零样本影响；
- 单场景地图编码器可能记忆位置，需要依赖空间块验证控制；
- 测试 outage 区域可能与训练分布不同，需要校准阈值。
