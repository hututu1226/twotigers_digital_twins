# Scheme D / Scheme E 5090 实验结果分析

## 1. 直接结论

两套方案均已完成 Fold0 验证、4000 条全量训练、500 条测试推理和结果打包，但都没有超过 Scheme C 的 Context 基线。

- Scheme D 把 Router 从“几乎只看 1 个邻居”修成了“约 42 个邻居参与”，分数却从 `0.6027` 降到 `0.5960`。这证明当前问题不是邻居数量不足，而是不同传播结构没有对齐就被平均，PAS 被抹平。
- Scheme E 的频谱教师有可用信息，OOF PAS/PDP 达到 `0.6009/0.7695`；但 Fold0 基站 1 的 NMSE 达到 `966.82`，总 NMSE 达到 `684.40`。它的主要故障是功率、投影和零信道链路失控，不是 GP 完全没有学到频谱。
- Scheme C 的 AE 重建分数仍为 `0.9491`。因此当前上限不是 AE，而是“如何从位置、环境和已知样本构造正确的目标 latent”。

通俗地说，Scheme D 像把 42 张没有对齐的人脸照片直接叠加，结果轮廓变糊；Scheme E 像轮廓猜得还可以，但把部分照片亮度放大了几百倍。Scheme F 必须先选少量同类参考、逐个对齐，再融合，并把亮度控制从图像纹理预测中独立出来。

## 3. 统一评分方式

项目代码使用的评分公式为：

```text
Score = 0.4 * PAS + 0.4 * PDP + 0.2 / (1 + NMSE)
```

这意味着三个指标必须一起改善。举例：

- `PAS=0.65, PDP=0.80, NMSE=0.60` 时，Score 约为 `0.705`；
- `PAS=0.62, PDP=0.79, NMSE=0.75` 时，Score 只有约 `0.678`。

所以达到 `0.70` 不能只修功率，也不能只提高 PAS。Scheme F 的工程目标至少应接近 `PAS >= 0.65`、`PDP >= 0.80`、`NMSE <= 0.60`。

## 5. Scheme D 实测分析

### 5.1 Fold0 指标

| 指标 | Scheme C | Scheme D | 变化 |
| --- | ---: | ---: | ---: |
| PAS | 0.5075 | 0.5017 | -0.0058 |
| PDP | 0.7629 | 0.7470 | -0.0159 |
| NMSE | 1.1153 | 1.0716 | 改善 0.0437 |
| Score | 0.6027 | 0.5960 | -0.0067 |
| Power MAE (log10) | 0.9658 | 0.9074 | 改善 0.0584 |
| 有效邻居 | 约 1--2 | 41.98 | 大幅增加 |
| Top1 mass | 接近 1 | 0.1070 | 塌缩已解除 |

Scheme D 确实修好了 Router 塌缩，并略微改善了功率和 NMSE；但 PAS/PDP 同时下降。说明把许多邻居的 latent 共同平均，会混合来自不同遮挡面、反射簇和角度簇的信号。

### 5.2 Warp 没有承担预期任务

- Spectrum 平均位移：`0.0367` 个 latent bin；
- Detail 平均位移：`0.1460` 个 latent bin；
- Warp saturation：`0`。

允许范围远大于实际位移，因此不是“范围太小”。更可能的原因是一个全局三轴位移无法描述多个多径簇各自不同的移动，模型选择了近似不动，再依靠残差网络修补。

### 5.3 训练状态

- Fold0：3435/565，最佳 checkpoint 为 epoch 114，164 epoch 早停；
- Fold0 Context 训练：2973.6 秒，约 49.6 分钟；
- Final：4000 条，127 epoch，2162.2 秒，约 36.0 分钟；
- 测试推理：35.6 秒；
- 最终输出：`[500,256,4,192]`、`complex64`、有限值、0 个预测 outage。

继续把 Scheme D 原样训练到 1000 epoch 的收益很低，因为它不是尚未收敛，而是已经在错误的融合方式上收敛。

## 6. Scheme E 实测分析

### 6.1 频谱教师并非失败

| 指标 | 全体 | BS0 | BS1 |
| --- | ---: | ---: | ---: |
| PAS | 0.6009 | 0.6584 | 0.5434 |
| PDP | 0.7695 | 0.8241 | 0.7149 |
| Power MAE (log10) | 0.7668 | - | - |

它比 Scheme D 更擅长预测粗角度形状，尤其是 BS0。该结果支持在 Scheme F 中继续使用 PAS/PDP 先验，但只能把它当作“形状提示”，不能让它直接决定最终绝对能量。

### 6.2 Hybrid 的致命问题在 BS1 功率

| 分组 | PAS | PDP | NMSE | Score |
| --- | ---: | ---: | ---: | ---: |
| 全部 | 0.5272 | 0.7428 | 684.40 | 0.5083 |
| BS0 | 0.5755 | 0.7765 | 1.4568 | 0.6222 |
| BS1 | 0.4698 | 0.7028 | 966.82 | 0.4692 |

BS1 的 NMSE 不是普通偏差，而是数值级别的灾难。交替投影的幅度缩放、GP 功率、UE 能量和 outage 误判组合后，使少量样本的绝对能量远高于真值；NMSE 采用全局误差能量累计，少数爆点即可拖垮整组。

### 6.3 投影有小幅形状收益，但不能解决根因

| 投影轮数 | PAS | PDP | Score |
| ---: | ---: | ---: | ---: |
| 0 | 0.4831 | 0.7291 | 0.4852 |
| 2 | 0.5259 | 0.7440 | 0.5083 |
| 4 | 0.5272 | 0.7428 | 0.5083 |
| 8 | 0.5283 | 0.7416 | 0.5083 |

2--4 轮对频谱形状有效，之后基本饱和。Scheme F 不应继续增加投影轮数，而应把投影改为保持单位能量的软约束，并由不确定度决定是否采用。

### 6.4 outage 风险

OOF outage 分类器：

- precision `0.6886`；
- recall `0.4389`；
- 预测 167 个，真实 262 个；
- final 测试输出 19 个精确零信道。

precision 约 0.69 表示每预测 10 个零信道，历史验证中约有 3 个可能被误杀。对完整复数信道而言，误杀代价很大。Scheme F 必须采用更保守的高精度门槛和多折一致性，而不是直接沿用 `0.46`。

## 7. 对 Scheme F 的硬约束

1. 不能再把 40 多个未对齐 latent 做全局平均。
2. 不能只为每个邻居预测一个全局 Warp；不同角度/时延簇需要不同位移或选择。
3. 不能让 PAS/PDP 投影改变最终总能量。
4. 不能让 GP 功率无边界地进入解码器。
5. 两个基站必须具有独立的功率、outage 和频谱校准头，并分别报告指标。
6. 30,720 维 latent 必须一直保持 Spectrum/Detail 网格，不允许 `30720 -> 几百 -> 30720` 的全连接瓶颈。
7. 验证必须同时按基站、最近支持距离和 outage 类型拆分；只看总 Score 会掩盖 BS1 爆点。

## 8. 本次运行时间与云端状态

两套方案从启动到关机的实际墙钟时间约 1 小时 57 分钟，比原保守估计明显更快。AutoDL 实例已关机，不再产生 GPU 计费。

这次实测说明 5090 足以在一次夜间任务内完成 Scheme F 的诊断、Fold 训练、全量训练、测试生成和打包，但必须继续保留自动关机和每阶段校验，不能把“脚本退出码”直接等同于“训练结果有效”。
